# Body Metrics Landing Page

Лендинг для Telegram-бота Body Metrics - анализ фигуры по фото.

## Деплой

Этот репозиторий настроен для GitHub Pages. После пуша в ветку `main`, сайт будет доступен по адресу:
`https://[ваш-username].github.io/[название-репозитория]/`

## Локальный запуск

Для локального тестирования используйте любой статический сервер:

```bash
# Python
python -m http.server 8000

# Node.js (http-server)
npx http-server -p 8000

# PHP
php -S localhost:8000
```

Затем откройте http://localhost:8000
